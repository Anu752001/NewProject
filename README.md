# Simple C++ Calculator

A command-line calculator that supports addition, subtraction, multiplication, and division.

## Build with CMake

```powershell
cmake -S . -B build
cmake --build build
```

## Run

```powershell
.\build\Debug\calculator.exe
```

On a single-config generator, use `.\build\calculator.exe`.

Enter expressions such as `12 + 3`, `20 - 8`, `6 * 7`, or `15 / 3`.
